# 🚀 Tech Stack Revolution: Before & After AI Era

## Overview
An in-depth data analysis project examining how the AI boom (ChatGPT launch - Nov 2022) 
dramatically shifted programming language trends on GitHub from 2019 to 2024.

## 🎯 Core Question
"How did the programming language landscape change before vs after AI exploded?"

## 📊 Key Findings
- All languages showed decreased GitHub push activity after ChatGPT launch
- Python leads with 29.4% market share in 2024
- JavaScript declined by -81.9% after AI era
- TypeScript grew significantly in the post-AI era

## 📈 Visualizations
1. Programming Language Trends (2019-2024)
2. Before AI vs After AI GitHub Activity
3. Language Growth Rate After AI Era
4. 2024 GitHub Language Market Share

## 🛠️ Technologies Used
- Python 3
- Pandas — Data processing
- Matplotlib — Visualizations
- Seaborn — Advanced charts
- Git & GitHub — Version control

## 📁 Dataset
- Source: GitHut 2.0 (GitHub Archive data)
- Coverage: 2019-2024 quarterly push events
- Languages: Python, JavaScript, TypeScript, Rust, Java, Go
